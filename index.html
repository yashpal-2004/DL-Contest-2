Unit 1: Transfer Learning

Transfer Learning

Reusing a model trained on one task for another related task. Example: reuse a model trained on 1 million images (cats, dogs, cars, birds) to detect disease using only 500 medical X-rays. It means less training time, less data required and potentially better performance, especially with a small target dataset.

Pretrained Models

A model already trained on a large dataset before a new task. Popular pretrained CNNs:

  • VGG16: simple, deep architecture; uses 3×3 convolution filters; 16 weight layers.
  • ResNet: uses skip/residual connections; helps address vanishing gradients in very deep networks.
  • MobileNet: lightweight for mobile and edge devices; uses depthwise separable convolutions.
  • Inception (GoogLeNet): uses multiple filter sizes in parallel to capture features at different scales.

Feature hierarchy: early layers generally learn basic features such as edges, corners and textures; deeper layers learn complex features such as objects, faces and shapes.

Feature Extraction

Use a pretrained model to extract useful features from new images:

  1. Take a pretrained model.
  2. Remove its final classification layer.
  3. Pass the new dataset through the model.
  4. Extract learned features.
  5. Train a new classifier on those features.

Example: pretrained ResNet → feature extraction → new classifier → disease prediction. Pretrained layers stay frozen; only the new classifier is trained. It is faster and useful with a small target dataset.

Layer Freezing and Fine-Tuning

Layer freezing prevents selected layers’ weights from updating during training. Frozen weights do not change; unfrozen weights can change through backpropagation.

Feature ExtractionFine-Tuning
Most/all pretrained layers frozenSome pretrained layers unfrozen
Train new classifierTrain classifier + selected pretrained layers
FasterSlower
Less data requiredUsually needs more data

Example fine-tuning: first 10 layers frozen, last 5 layers trainable, new classifier trainable. Fine-tuning generally uses a lower learning rate because pretrained weights already contain useful knowledge.

Data Augmentation

Create modified versions of existing training images to increase dataset diversity. Techniques: horizontal flip, rotation, random cropping, scaling, translation, zooming, random erasing and Gaussian noise.

  • Reduces overfitting.
  • Improves generalization.
  • Increases effective training-data diversity.
  • Makes the model robust to variations.

Usually apply augmentation to training data, not validation/test data. Transformations should preserve the label; flipping a handwritten 6 could make it resemble a 9.

CNN Limitations — Motivation for ViT

CNN uses convolution filters to detect local patterns such as edges, textures and shapes. Limitations:

  1. Local receptive field: primarily focuses on nearby pixels and local patterns.
  2. Limited global context: distant-region relationships can be difficult to capture.
  3. Translation equivariance: feature maps shift when input images shift; not inherently translation invariant.
  4. Inductive bias: assumes locality and spatial structure, which may limit flexibility for some tasks.
  5. Long-range dependencies: far-apart relationships may require deeper layers or larger receptive fields.

Vision Transformer (ViT)

Applies Transformer architecture to image recognition: divide an image into small patches, convert each patch to an embedding, add positional embeddings for spatial information, use self-attention to learn patch relationships, then make predictions.

Example dog image: CNN detects local features such as ears, eyes and fur; ViT can learn relationships between distant patches such as head and tail.

CNNViT
ConvolutionSelf-attention
Local feature extractionGlobal relationships through attention
Strong spatial inductive biasWeaker built-in spatial inductive bias
Often works well with smaller datasetsOften benefits from large-scale pretraining
Filters/kernelsImage patches

ViT does not automatically outperform CNN. It often needs substantial data and compute, though pretrained ViTs can work well on smaller datasets through transfer learning.

Unit 2: Recurrent Neural Networks

Sequential Data Intuition

Sequential data has elements whose order matters: text (“I love Deep Learning”), speech/audio, time series (daily temperature, stock prices) and video frames. Normal ANNs generally process independent inputs; RNNs use previous information to process current input. “Dog bites man” and “Man bites dog” have different meanings.

Why RNN? Traditional neural networks expect fixed-size input, have no memory of previous input and do not naturally handle sequential dependencies. RNNs handle sequential input, carry previous information through hidden state and process variable-length sequences.

RNN Architecture

Recurrent Neural Network carries previous information forward through hidden state. Components: current input xₜ, hidden state hₜ (memory) and output yₜ.

\(hₜ = f(Wₓₕxₜ + Wₕₕhₜ₋₁ + bₕ)\)\(yₜ = g(Wₕᵧhₜ + bᵧ)\)
SymbolMeaning
xₜCurrent input
hₜCurrent hidden state
hₜ₋₁Previous hidden state
WₓₕInput-to-hidden weights
WₕₕHidden-to-hidden weights
WₕᵧHidden-to-output weights
bBias
fActivation function, often tanh
gOutput activation

Exam trick: current hidden state depends on both current input and previous hidden state. Example: “I love AI”: I → h₁; love + h₁ → h₂; AI + h₂ → h₃.

RNN Unrolling and Weight Sharing

Unrolling expands an RNN across multiple time steps. For input A → B → C: x₁ → h₁; x₂,h₁ → h₂; x₃,h₂ → h₃. The same network is shown at each time step.

  1. Same weights shared across all time steps.
  2. Each step processes one sequence element.
  3. Hidden state carries information forward.
  4. Longer sequence means more unrolled computational steps.

For 100 words, RNN reuses the same weights rather than creating new weights per word. This means fewer parameters, efficient learning and support for variable-length sequences. MCQ favourite: RNN shares weights across time.

Types of RNN Architectures

One-to-One

Example: traditional image classification.

One-to-Many

Example: image caption generation.

Many-to-One

Example: sentiment analysis.

Many-to-Many

Example: machine translation.

Long-Term Dependencies

A current prediction may depend on information from far earlier in the sequence. Example: understanding the relationship between “students” and “passed” in a long sentence may require remembering information across many words.

Vanishing Gradient

During backpropagation gradients repeatedly multiply. If multiplied by small values they become very small: 0.5 × 0.5 × 0.5 × 0.5 = 0.0625. Earlier layers receive almost zero gradient, weights do not update properly, and long-term dependencies are hard to learn.

Exploding Gradient

If gradients repeatedly multiply by large values, they become very large: 2 × 2 × 2 × 2 = 16. This can cause unstable training, huge weight updates and loss to fluctuate or become NaN.

Vanishing GradientExploding Gradient
Gradient becomes very smallGradient becomes very large
Learning becomes slowTraining becomes unstable
Earlier dependencies forgottenHuge weight updates
Clipping does not directly solve itGradient clipping helps

Solutions

  1. LSTM: memory cell and gates preserve long-term information.
  2. GRU: update and reset gates; simpler than LSTM.
  3. Gradient clipping: limits gradient magnitude to prevent exploding gradients.
  4. Proper initialization: helps maintain stable gradients.
LSTMGRU
3 gates: Input, Forget, Output2 gates: Update, Reset
Separate cell and hidden statesUses hidden state

Both help capture long-term dependencies.

Unit 3: Gated Architectures

LSTM, GRU aur Bidirectional RNNs — architecture, gates, formulas aur comparison.

1. LSTM — Long Short-Term Memory

LSTM ki zarurat kyun padi?

Traditional RNN mein vanishing gradient problem hoti hai: RNN purani information bhool sakta hai, long sequences learn karna difficult hota hai, aur distant time steps ke beech dependencies capture nahi ho pati. LSTM gates and a cell state use karke important information ko longer time tak remember kar sakta hai.

LSTM ke 2 important states

  1. Cell State (Cₜ): Long-term memory; information ko carry karta hai.
  2. Hidden State (hₜ): Current output / short-term representation.

LSTM ke 3 gates

Forget Gate

Purani memory ka kitna part forget karna hai: \(fₜ = σ(Wf[hₜ₋₁, xₜ] + bf)\) Output 0 to 1: 0 = completely forget; 1 = completely retain.

Input Gate

New information ka kitna part memory mein add karna hai: \(iₜ = σ(Wi[hₜ₋₁, xₜ] + bi)\)

Candidate memory: \(C̃ₜ = tanh(Wc[hₜ₋₁, xₜ] + bc)\)

Output Gate

Current cell memory ka kitna part output mein dikhana hai: \(oₜ = σ(Wo[hₜ₋₁, xₜ] + bo)\)

Most important LSTM equations

\(Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ\)

Previous memory × Forget Gate; new candidate memory × Input Gate; dono combine karke new memory.

\(hₜ = oₜ ⊙ tanh(Cₜ)\)

Output gate decides updated cell state ka kitna part hidden state banega. Exam favourite: LSTM has 3 gates: Forget, Input, Output.

2. GRU — Gated Recurrent Unit

GRU long-term dependencies handle karta hai and is a simpler alternative to LSTM.

Update Gate

Previous vs new information: \(zₜ = σ(Wz[xₜ, hₜ₋₁] + bz)\)

Reset Gate

Candidate state calculate karte waqt past information kitna ignore karna hai: \(rₜ = σ(Wr[xₜ, hₜ₋₁] + br)\)

Candidate hidden state: \(h̃ₜ = tanh(Wh[xₜ, rₜ ⊙ hₜ₋₁] + bh)\)

Final hidden state (common convention): \(hₜ = (1 − zₜ) ⊙ hₜ₋₁ + zₜ ⊙ h̃ₜ\)

Important: Different textbooks/frameworks may use the opposite update-gate convention, so check the provided equation.

GRU working

  • Update gate decides old vs new information.
  • Reset gate controls the use of previous hidden state in candidate calculation.
  • Final hidden state combines old and candidate information.

Remember: GRU has no separate cell state. It uses hidden state as its memory.

When to use: LSTM when complex long-term dependencies and separate memory control are useful. GRU when a simpler architecture with fewer parameters and potentially faster training is desired.

Contest trick: LSTM = 3 gates + 2 states. GRU = 2 gates + 1 state. GRU generally has fewer parameters than an equivalent LSTM with the same input and hidden dimensions.

4. Bidirectional RNNs (BiRNN)

Normal RNN processes a sequence in one direction: Past → Future. Bidirectional RNN processes in both forward and backward directions.

Example: “The movie was not good”. To understand “good”, “not” matters. Forward: The → movie → was → not → good. Backward: good → not → was → movie → The. Both directions' information is combined.

Forward hidden state: \(→hₜ = RNNf(xₜ, →hₜ₋₁)\)

Backward hidden state: \(←hₜ = RNNb(xₜ, ←hₜ₊₁)\)

Combined representation: \(hₜ = [→hₜ ; ←hₜ]\) Here ; means concatenation.

Advantages

  • Uses past and future context
  • Better contextual understanding
  • Useful for NLP tasks
  • Can improve sequence labeling performance

Applications

  • Sentiment Analysis
  • Named Entity Recognition (NER)
  • Speech Recognition
  • Part-of-Speech Tagging
  • Text Classification

Limitations

  • More computation than one-directional RNN
  • Usually needs the complete sequence before producing fully bidirectional representations
  • Not suitable for strict real-time causal prediction when future inputs are unavailable

Important MCQ: Bidirectional RNN uses both past and future context.

5. Quick Conceptual Revision

Traditional RNN

One hidden state; struggles with long-term dependencies.

LSTM

Forget + Input + Output gates; cell state + hidden state; 3 gates.

GRU

Reset + Update gates; only hidden state; 2 gates.

Bidirectional RNN

Forward + backward processing; uses past + future context.

Important exam traps

  1. LSTM does not completely eliminate vanishing gradients; it helps mitigate the problem.
  2. GRU has no separate cell state.
  3. Forget gate belongs to LSTM, not standard GRU.
  4. Reset gate belongs to GRU.
  5. Bidirectional RNN is not the same as a two-layer stacked RNN.
  6. Bidirectional models are not generally suitable for future-unavailable real-time predictions.

Unit 4: Text Representation

Computer directly human language understand nahi karta. Text ko numerical form mein convert karna padta hai, so machine learning models can process it.

Text Representation

Converting textual data into numerical vectors. Example: “I love Deep Learning” → [0.2, 0.5, 0.8, 0.9] (illustrative values).

Techniques: Tokenization · Bag of Words (BoW) · TF-IDF

1. Tokenization Very Important

Breaking text into smaller units called tokens. Tokens can be words, sentences, subwords, or characters.

Word tokenization

“I love Machine Learning” → [“I”, “love”, “Machine”, “Learning”]

Sentence tokenization

“I love AI. AI is interesting.” → [“I love AI.”, “AI is interesting.”]

Character tokenization

“CAT” → [“C”, “A”, “T”]

Subword tokenization

“unhappiness” → [“un”, “happi”, “ness”]. Useful for rare and unknown words. Algorithms: BPE (Byte Pair Encoding), WordPiece, SentencePiece.

Important tokenization concepts

  • Vocabulary: Unique tokens in the corpus. “I love AI” and “I love ML” → [“I”, “love”, “AI”, “ML”], size = 4.
  • Corpus: Collection of text documents.
  • Stop words: Common words such as is, the, a, an, and; sometimes removed because they may carry less useful information for a task.

Stemming

Cuts word endings using rules; can produce invalid words; faster. Example: Studies → Studi.

Lemmatization

Converts to dictionary base form; meaningful and linguistically informed. Example: Studies → Study.

Exam trick: Tokenization creates tokens; it does NOT automatically convert them into meaningful numerical vectors.

2. Bag of Words (BoW) Very Important · Numericals

Converts documents into numerical vectors based on word frequency. It considers word presence and frequency; it ignores grammar, sentence structure, and word order.

Step-by-step example

Documents: D1 “I love AI”; D2 “I love ML”; D3 “I love AI AI”. Vocabulary [AI, I, love, ML], size = 4.

DocumentAIIloveMLVector
D11110[1, 1, 1, 0]
D20111[0, 1, 1, 1]
D32110[2, 1, 1, 0]

Binary BoW: Present = 1, absent = 0. Count-based BoW: Counts occurrences; “AI AI AI ML” → [3, 1].

Advantages

  • Simple and easy to implement
  • Fast
  • Useful for basic text classification
  • Easy to understand

Limitations

  • Ignores word order
  • Ignores semantic meaning
  • Creates sparse vectors (mostly zeros)
  • Vocabulary becomes very large for big datasets

“Dog bites man” and “Man bites dog” can have identical BoW representations because word order is ignored.

3. TF-IDF Most Important · Formula + Numericals

Term Frequency–Inverse Document Frequency gives importance based on how frequently a word appears in one document and how rare it is across all documents. A word frequent in one document but rare in the corpus has higher TF-IDF.

TF — Term Frequency

Measures how frequently a term appears in a document.

\(TF(t, d) = count of term t in d ÷ total terms in d\)

“AI is AI powerful”: total words = 4; AI count = 2; TF(AI, d) = 2/4 = 0.5.

IDF — Inverse Document Frequency

Measures how rare or informative a term is across the corpus.

\(IDF(t) = log(N / DF(t))\)

N = total documents; DF(t) = documents containing t; log is usually natural logarithm or another specified base. A word in every document has IDF = 0 under the standard unsmoothed formula. A word in very few documents has higher IDF.

TF-IDF

\(TF-IDF(t, d) = TF(t, d) × IDF(t)\)

Term importance in a particular document.

Numerical example

D1 “AI is powerful AI”; D2 “AI is useful”; D3 “ML is powerful”. Find TF-IDF of “powerful” in D1.

  1. TF = 1/4 = 0.25.
  2. “powerful” appears in D1 and D3, so DF = 2; N = 3.
  3. IDF = ln(3/2) = 0.4055.
  4. TF-IDF = 0.25 × 0.4055 = 0.1014.
BoWTF-IDF

TF-IDF advantages

  • Reduces importance of very common words
  • Highlights informative words
  • Useful for document classification
  • Useful in information retrieval and search engines

TF-IDF limitations

  • Does not understand semantic meaning
  • Ignores word order
  • Creates sparse vectors
  • Synonyms are treated as different words

Unit 5: Word Embeddings

BoW and TF-IDF do not understand word meaning, do not give similar words similar representations, and do not capture semantic relationships. Word Embeddings convert words into dense, low-dimensional numerical vectors that capture semantic and syntactic relationships. Example vectors: King [0.8, 0.2, 0.5], Queen [0.7, 0.3, 0.6], Banana [−0.4, 0.9, 0.1] (illustrative). King and Queen are generally closer in vector space.

BoW / TF-IDFWord Embeddings
Sparse, usually high-dimensionalDense, usually low-dimensional
No semantic understandingCan capture semantic relationships
Words treated independentlySimilar words can have similar vectors

Word embeddings are learned numerical representations of words.

Word2Vec

A popular shallow neural network-based model that learns word vectors using surrounding words and context. Its two architectures are CBOW and Skip-Gram.

CBOW — Continuous Bag of Words

Predicts the target (center) word using surrounding context words. “The cat sits on the mat”: context “The, cat, on, the” → target “sits”. Working: take context words, convert them into embeddings, commonly average the context, predict the target, then update embeddings during training. Input = context; output = target. CBOW = Context → Target. It is generally efficient for frequent words and uses a fixed context window.

Skip-Gram

Predicts surrounding context words using the center word. “The cat sits on the mat”: input “sits” → context “The, cat, on, the”. Skip-Gram = Target → Context. It is generally slower and often performs well for rare words.

FeatureCBOWSkip-Gram
InputContext wordsCenter word
OutputTarget wordContext words
DirectionContext → TargetTarget → Context
TrainingGenerally fasterGenerally slower
PerformanceOften good for frequent wordsOften good for rare words

How Word Embeddings are Learned

  1. Create a vocabulary.
  2. Assign initial embedding vectors.
  3. Create training examples using context windows.
  4. Train a neural network to predict target/context words.
  5. Update embedding weights using backpropagation.
  6. Extract the learned embedding matrix.
  • Embedding dimension: number of values in a word vector. [0.2, 0.5, 0.8, 0.1] has dimension 4; real models commonly use 100 or 300.
  • Context window: number of surrounding words considered. In “I love deep learning today”, target “deep”, window size 2 → “love, I, learning, today” where available.
  • Negative sampling: learns to distinguish genuine context words from randomly sampled negative words instead of predicting every vocabulary word. It is faster and computationally efficient, especially for large vocabularies.
  • Cosine similarity: \((A · B) / (||A|| ||B||)\). +1 = same direction/highly similar; 0 = orthogonal; −1 = opposite directions. It measures vector direction, not simply Euclidean distance.

Embedding Applications

  1. Sentiment Analysis: detect positive, negative or neutral sentiment. “This movie is amazing” → Positive.
  2. Machine Translation: represent words across languages.
  3. Semantic Search: find results by meaning, not only exact keyword matching.
  4. Chatbots: represent queries and understand language context.
  5. Named Entity Recognition (NER): identify names, places and organizations.
  6. Recommendation Systems: find semantically related products, content or documents.

Static vs Contextual Word Embeddings

Static

A word gets the same vector regardless of its sentence. Examples: Word2Vec, GloVe, FastText.

Contextual

A word representation changes according to surrounding context. Examples: BERT, ELMo.

“Bank” in “I deposited money in the bank” and “I sat near the river bank”: static embedding generally uses the same vector; contextual embedding changes with meaning. Contest trick: Word2Vec is static; BERT generates contextual representations.

Unit 6: Sequence-to-Sequence Models

Seq2Seq models convert an input sequence into an output sequence; input and output lengths may differ. Example: English “How are you?” → French “Comment ça va?” Applications: Machine Translation, Text Summarization, Chatbots, Question Answering and Speech Recognition. Seq2Seq handles variable-length inputs and outputs.

Encoder-Decoder Architecture

A Seq2Seq model has two components: Encoder processes the input sequence and converts its information into a context representation. Decoder uses encoder information to generate output tokens. It receives the representation, uses an initial state/context, feeds the previous output token at the next step, predicts the next token, then continues until EOS.

EncoderDecoder
Processes and encodes input sequenceGenerates output sequence
Creates context representationUses encoded information
Reads inputPredicts next token / generates output

Complete Working of Seq2Seq

Example input “I am happy”; output “Je suis heureux”. Encoder receives each input token and updates its hidden state, then produces a sequence representation. Decoder generates: Je → suis → heureux → EOS. Encoder and decoder can use RNN, LSTM or GRU. Modern Seq2Seq architectures can also use Transformers.

Context Vector

A fixed-size numerical representation that summarizes input information and passes it from encoder to decoder. It connects the encoder and decoder. In basic RNN-based Seq2Seq it is often derived from the encoder’s final hidden state and is usually fixed-size in traditional architectures.

Example: “The weather is beautiful today” → illustrative C = [0.2, 0.5, 0.8, 0.3]. The decoder uses this vector to generate the translation.

Context Vector Bottleneck

Traditional Seq2Seq compresses the entire input into one fixed-size context vector. A short 3-word sentence and a long 100-word sentence must both fit into the same fixed size; information can be lost.

  1. Long-sequence information may be lost.
  2. Decoder may struggle to remember important earlier words.
  3. Translation quality may decrease.
  4. Model may struggle with long-range dependencies.
  5. Fixed-size representation may not capture all input details.

Solution — Attention: instead of relying only on one fixed vector, the decoder can look at different encoder hidden states while generating each output word. For input “The cat is sitting on the mat” while generating “chat”, example attention weights: The 0.05, cat 0.70, is 0.05, sitting 0.10, on 0.05, mat 0.05. Attention reduces, but does not necessarily eliminate, this bottleneck.

Teacher Forcing

During training, Teacher Forcing feeds the actual previous target token to the decoder instead of its previous predicted token. For actual output “I love AI”, the actual previous token “I” is fed at the next step. Without it, the decoder uses its own previous prediction.

Advantages: faster training and helps stabilize learning. Limitation: during inference, actual target tokens are unavailable and the decoder must use its own predictions. This training/inference difference creates exposure bias.

Unit 7: Attention Mechanism

Traditional Seq2Seq compresses the full input into one fixed-size context vector. Long sentences may lose information and it can be difficult for the decoder to identify important words. Attention lets the decoder focus on relevant parts of the input while generating each output token. Example: for “The cat is eating fish”, while generating “chat”, the model can give “cat” high importance.

Why Attention?

  1. Reduces the context-vector bottleneck.
  2. Focuses on important input words.
  3. Helps handle long sequences.
  4. Can improve translation and sequence generation.
  5. Can create different context vectors for different output words.

Query, Key and Value

ComponentMeaningLibrary analogy
Query (Q)Decoder’s current information/requestYour question
Key (K)Encoder states’ matching representationsBook index/title
Value (V)Encoder states’ informationInformation in books

The model compares the query with keys and selects relevant values.

How Attention Works

  1. Calculate a similarity/alignment score between the query and each key.
  2. Apply softmax to convert scores into attention weights: \(αᵢ = exp(eᵢ) / Σⱼ exp(eⱼ)\)
  3. Calculate the context vector: \(c = Σᵢ αᵢVᵢ\)

αᵢ is an attention weight; Vᵢ is a value vector; c is the context. Attention weights generally lie between 0 and 1 and sum to 1.

Bahdanau Attention — Additive

Introduced by Dzmitry Bahdanau and colleagues in 2014. It uses a feed-forward neural network to combine encoder and decoder hidden states.

Encoder state hᵢ; previous decoder state sₜ₋₁. Alignment score: \(eₜᵢ = vₐᵀ tanh(Wₐsₜ₋₁ + Uₐhᵢ)\). Wₐ and Uₐ are learnable matrices; vₐ is a learnable vector. Weights: \(αₜᵢ = exp(eₜᵢ) / Σⱼ exp(eₜⱼ)\). Context: \(cₜ = Σᵢ αₜᵢhᵢ\). It is additive because transformed representations are added before the nonlinearity. It uses tanh, learned parameters and commonly the previous decoder state.

Luong Attention — Multiplicative

Introduced by Minh-Thang Luong and colleagues in 2015. It calculates scores using dot products or matrix multiplication between decoder and encoder states. Let hₜ be the current decoder state and h̄ₛ the encoder state.

Dot

\(score(hₜ,h̄ₛ) = hₜᵀh̄ₛ\)

Direct dot product; no extra learned matrix; requires compatible dimensions.

General

\(score(hₜ,h̄ₛ) = hₜᵀWₐh̄ₛ\)

Uses a learnable matrix; more flexible than Dot.

Concat

\(score(hₜ,h̄ₛ) = vₐᵀ tanh(Wₐ[hₜ;h̄ₛ])\)

Concatenates both states and uses a neural network; additive-style scoring.

Luong steps: decoder generates current hidden state; compare it with encoder states; calculate alignment scores; apply softmax; calculate weighted context; combine context with decoder representation to generate output.

\(αₜₛ = exp(score(hₜ,h̄ₛ)) / Σⱼ exp(score(hₜ,h̄ⱼ))   cₜ = Σₛ αₜₛh̄ₛ\)

Global vs Local Attention

  • Global: considers every encoder hidden state in the entire input.
  • Local: focuses on a selected window/region; can reduce computation and is useful when nearby positions matter.

Clarification: Dot and General are the main multiplicative scoring functions; Concat is also described with Luong scoring functions but is additive-style.

Numerical Example — Attention Weights

Scores e = [1, 2, 0]. Softmax gives approximately [0.245, 0.665, 0.090]. Position 2 has the highest attention. Attention generally assigns normalized weights to all positions and computes a weighted sum; it does not simply choose only the highest-scoring word.
